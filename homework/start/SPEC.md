# SPEC

## Requirement
Я пользователь и я хочу, чтобы задачи, у которых нет названия (пустое, из обычных пробелов, переносов строк или невидимых пробелов нулевой ширины `U+200B`), не сохранялись при переименовании, а существующие такие записи не были видны в списке и не учитывались при подсчёте открытых задач.

## Acceptance tests
- R1: Если при переименовании ввести только пробелы, табуляцию (`\t`), неразрывный пробел (`\u00A0`) или пробел нулевой ширины (`U+200B` / `\u200B`), название задачи не меняется, а на экране появляется сообщение «Название не может быть пустым». Если в названии есть текст, все эти символы (включая `U+200B`) по краям обрезаются при создании и переименовании.
- R2: Задачи с пустым названием (в том числе старая пустая строка с `id: 3` из `seedTasks` и записи только из `U+200B`) не показываются в списке ни во вкладке «Все», ни в «Открытых», ни в «Готовых».
- R3: Счётчик «Открытых» не считает задачи, у которых название состоит из одних пробельных символов или `U+200B` (на стартовых данных должно показывать `1`, а не `2`).

## Non-goals
- Не удаляю пустую задачу из массива `seedTasks` вручную — она должна отфильтровываться самой логикой доски.
- Не прикручиваю новые фичи вроде галочек выполнения, удаления задач, `localStorage` или бэкенда.
- Не меняю дизайн и вёрстку, только добавляю вывод текста ошибки при неудачном переименовании.

## Files in scope
- `src/tasks.ts`
- `src/App.tsx`

## Definition of done
- Проходят все тесты (`npm test`).
- Собирается проект без ошибок типов (`npm run build`).
- В браузере видно «Открытых: 1», пустых строк в списке нет, а при попытке сохранить пробелы при переименовании выводится «Название не может быть пустым».
